# Acrodea_Runtime

## 简介

一个Ggee游戏商店启动器 （psvita 安卓游戏移植项目）

## 支持平台

* Sony Ps Vita

## 开发人员

* 一直改
* SpriteLisen
* KAAAsS

## 如何编译

需要安装好[Vitasdk](https://github.com/vitasdk)，并克隆好项目。

执行cmake即可，会自动编译好所需的一切。
